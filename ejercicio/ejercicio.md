# Mini Ejercicio: Secondary Sort y Join

## Parte 1: Secondary Sort
Imagina que tienes el siguiente dataset de ventas de sucursales (Sucursal, Monto):
Norte   150
Sur     500
Norte   300
Sur     200

**Pregunta:** ¿Cuál sería la "Llave Compuesta" exacta que emite la fase Map para la primera línea ("Norte 150")?

## Parte 2: Join
Tienes estos dos registros cruzando:
`estudiantes.txt`: 1 Ana
`calificaciones.txt`: 1 Matematicas

**Pregunta:** Durante el Join, ¿Qué llave emite el Map y qué valores agrupa para realizar el cruce del ID 1?
